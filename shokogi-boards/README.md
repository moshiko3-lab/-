# Shokogi Boards: חבילה לבניית התוכנה

## מה יש בתיקייה

| קובץ / תיקייה | מה זה |
|---|---|
| `PROMPT.md` | ההודעה שמדביקים ל-Claude Code |
| `SPEC.md` | המפרט המלא: הטכנולוגיה, כל המסכים, העיצוב, ההרשאות ושלבי הבנייה |
| `prototype/` | האפליקציה הנוכחית (HTML) כדוגמה מדויקת של איך הכל צריך להיראות ולהתנהג |
| `migration/` | הנתונים האמיתיים שלך: 95 הגלשנים, ההיסטוריה, התמונות ושמות קובצי התמונות |

## איך מתחילים

1. שומרים את התיקייה הזו במקום קבוע, למשל `Documents/shokogi-app`.
2. פותחים Claude Code על התיקייה הזו.
3. מעתיקים את כל התוכן של `PROMPT.md` ומדביקים כהודעה הראשונה.
4. Claude Code יסביר בעברית מה הוא עומד לעשות, ויבקש ממך לפתוח חשבונות חינמיים ב-Vercel וב-Supabase, עם הוראות צעד אחר צעד.
5. הוא יבנה בשלבים ויעצור אחרי כל שלב עם סיכום קצר. אפשר לבקש שינויים בכל שלב.

## חשוב

- **נתונים עדכניים:** המשך לעבוד עם האפליקציה הנוכחית עד שהתוכנה החדשה מוכנה. לפני ההעברה הסופית, Claude Code יבקש עותק עדכני של `data.json` ושל תיקיית `photos`.
- **סוג התוכנה:** אפליקציית ענן עם התחברות נפרדת לבעלים ולעובדים. נפתחת מכל מחשב, טלפון וטאבלט, ואפשר להתקין אותה על הטלפון כמו אפליקציה.
